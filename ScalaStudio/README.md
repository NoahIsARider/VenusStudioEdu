# ScalaStudio - Scala 语言学习项目

欢迎来到 ScalaStudio！这是一个全面的 Scala 语言学习项目，涵盖基础语法、面向对象与函数式编程特性。

## 📚 项目结构

```
ScalaStudio/
├── 01-basics/           # 变量与数据类型
├── 02-control/          # 控制流
├── 03-functions/        # 函数与高阶函数
├── 04-collections/      # 集合操作
├── 05-oop/              # 类、对象与模式匹配
├── README.md
├── main.scala
└── run.sh
```

## 🚀 快速开始

```bash
bash run.sh
```
