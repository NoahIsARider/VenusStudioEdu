# LispStudio - Lisp 语言及方言学习项目

欢迎来到 LispStudio！这是一个涵盖经典 Lisp 方言（Common Lisp、Scheme、Clojure 风格）的学习项目。

## 📚 项目结构

```
LispStudio/
├── 01-common-lisp/      # Common Lisp 基础
├── 02-scheme/           # Scheme 基础
├── 03-clojure-style/    # Clojure 风格语法
├── README.md
├── main.lisp
└── run.sh
```

## 🚀 快速开始

```bash
bash run.sh
```
