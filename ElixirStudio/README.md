# ElixirStudio - Elixir 语言学习项目

欢迎来到 ElixirStudio！这是一个基于 BEAM 虚拟机的高并发函数式编程语言 Elixir 学习项目。

## 📚 项目结构

```
ElixirStudio/
├── 01-basics/           # 基础语法与数据类型
├── 02-control/          # 控制流与模式匹配
├── 03-functions/        # 模块与函数
├── 04-collections/      # 列表与映射
├── README.md
├── main.ex
└── run.sh
```

## 🚀 快速开始

```bash
bash run.sh
```
