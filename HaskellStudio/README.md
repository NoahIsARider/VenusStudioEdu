# HaskellStudio - Haskell 语言学习项目

欢迎来到 HaskellStudio！这是一个全面的纯函数式编程语言 Haskell 学习项目。

## 📚 项目结构

```
HaskellStudio/
├── 01-basics/           # 基础语法与表达式
├── 02-functions/        # 函数与模式匹配
├── 03-types/            # 类型与类型类
├── 04-recursion/        # 递归与高阶函数
├── README.md
├── Main.hs
└── run.sh
```

## 🚀 快速开始

```bash
bash run.sh
```
