# Redis 有序集合 (Sorted Sets)

## 学习目标
- 理解有序集合的数据结构和特点
- 掌握有序集合的基本操作命令
- 学会使用有序集合实现排行榜、优先级队列等应用
- 了解有序集合的性能特性和使用场景

## 主要内容

### 1. 有序集合基础
- 什么是有序集合
- 有序集合与集合的区别
- 成员和分数的概念
- 有序集合的特点和优势

### 2. 基本操作
- ZADD：添加成员和分数
- ZREM：移除成员
- ZSCORE：获取成员分数
- ZCARD：获取有序集合大小
- ZCOUNT：统计指定分数范围内的成员数

### 3. 范围操作
- ZRANGE：按排名获取成员
- ZREVRANGE：按排名反向获取成员
- ZRANGEBYSCORE：按分数范围获取成员
- ZREVRANGEBYSCORE：按分数范围反向获取成员
- ZRANK/ZREVRANK：获取成员排名

### 4. 集合运算
- ZUNIONSTORE：有序集合求并集
- ZINTERSTORE：有序集合求交集
- 聚合函数（SUM、MIN、MAX）

### 5. 高级操作
- ZINCRBY：增加成员分数
- ZLEXCOUNT/ZRANGEByLEX：字典序操作
- ZPOPMIN/ZPOPMAX：弹出最小/最大元素
- BZPOPMIN/BZPOPMAX：阻塞式弹出操作

## 使用场景
- 排行榜系统（游戏积分、销售排行等）
- 优先级队列
- 时间序列数据存储
- 范围查询和分页
- 实时数据分析

## 最佳实践
- 合理设计分数值，避免精度问题
- 使用负数实现倒序排列
- 利用范围查询实现分页功能
- 注意有序集合的内存使用
- 对于大量数据考虑分片存储
