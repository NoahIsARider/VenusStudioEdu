# Redis 键操作

## 学习目标
- 掌握 Redis 键的基本操作命令
- 理解键的过期机制
- 学会键的模式匹配和批量操作

## 主要内容

### 键的基本操作
- EXISTS: 检查键是否存在
- DEL: 删除指定键
- TYPE: 获取键的数据类型
- RENAME/RENAMENX: 重命名键
- RANDOMKEY: 随机返回一个键

### 键的过期策略
- EXPIRE/PEXPIRE: 设置键的过期时间（秒/毫秒）
- EXPIREAT/PEXPIREAT: 设置键的过期时间戳（秒/毫秒）
- TTL/PTTL: 获取键的剩余生存时间（秒/毫秒）
- PERSIST: 移除键的过期时间

### 键的模式匹配
- KEYS: 查找所有符合给定模式的键
- SCAN: 增量迭代数据库中的键

### 批量操作
- MSET/MSETNX: 批量设置键值对
- MGET: 批量获取键值

## 最佳实践
- 合理设计键名命名规范
- 避免使用 KEYS 命令在生产环境中扫描大量键
- 合理设置键的过期时间以避免内存浪费

## 实践练习
- 实现一个带有过期时间的缓存系统
- 使用 SCAN 命令安全地遍历键空间
- 设计一套键名命名规范
