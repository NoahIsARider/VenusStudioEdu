# Redis 事务

## 学习目标
- 理解 Redis 事务的概念和特点
- 掌握事务的基本操作命令
- 学会使用事务实现原子性操作
- 了解 Redis 事务与传统关系型数据库事务的区别

## 主要内容

### 1. 事务基础
- 什么是 Redis 事务
- 事务的特点（原子性、隔离性）
- Redis 事务与 ACID 特性的关系
- 事务的使用场景

### 2. 事务命令
- MULTI：开启事务
- EXEC：执行事务
- DISCARD：取消事务
- WATCH：监视键
- UNWATCH：取消监视

### 3. 事务执行流程
- 事务命令排队
- 命令执行阶段
- 错误处理机制
- 事务结果返回

### 4. 事务与乐观锁
- WATCH 命令的作用
- 乐观锁实现机制
- CAS（Check-And-Set）操作
- 并发控制策略

### 5. 事务限制和注意事项
- 事务不支持回滚
- 语法错误和运行时错误的处理
- 事务中的嵌套问题
- 性能考虑

## 使用场景
- 批量操作的原子性保证
- 计数器的并发安全更新
- 复杂业务逻辑的一致性保证
- 分布式锁的实现

## 最佳实践
- 使用 WATCH 实现乐观锁防止竞态条件
- 避免在事务中执行长时间操作
- 注意事务中的错误处理
- 合理使用管道与事务结合
- 对于强一致性要求的场景考虑使用 Lua 脚本

## 实践练习
1. 实现一个带有余额检查的转账功能
2. 使用 WATCH 和事务实现安全的计数器更新
3. 创建一个简单的分布式锁机制
4. 实现一个带有库存检查的商品购买功能
5. 使用 Lua 脚本替代事务实现原子操作
