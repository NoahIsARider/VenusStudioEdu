# Redis 列表操作

## 学习目标
- 掌握 Redis 列表类型的基本操作命令
- 理解列表类型的使用场景
- 学会实现消息队列和最新列表等功能

## 主要内容

### 列表基本操作
- LPUSH/RPUSH: 从左侧/右侧插入元素
- LPOP/RPOP: 从左侧/右侧弹出元素
- LINDEX: 获取指定索引的元素
- LLEN: 获取列表长度
- LRANGE: 获取指定范围的元素

### 列表阻塞操作
- BLPOP/BRPOP: 阻塞式弹出元素
- BRPOPLPUSH: 阻塞式弹出并推入另一个列表

### 列表修改操作
- LSET: 设置指定索引的元素值
- LINSERT: 在指定元素前后插入新元素
- LREM: 删除指定数量的元素
- LTRIM: 修剪列表只保留指定范围的元素

### 列表高级操作
- RPOPLPUSH: 弹出右侧元素并推入另一个列表左侧
- LPOS: 查找元素在列表中的位置

## 使用场景
- 消息队列系统
- 最新消息列表（如微博时间线）
- 任务队列
- 浏览历史记录

## 最佳实践
- 合理控制列表长度避免内存占用过大
- 根据使用场景选择合适的插入和弹出方向
- 使用阻塞操作实现高效的消息处理
