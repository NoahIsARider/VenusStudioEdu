# Redis 字符串操作

## 学习目标
- 掌握 Redis 字符串类型的基本操作命令
- 理解字符串类型的使用场景
- 学会实现计数器和分布式锁等功能

## 主要内容

### 字符串基本操作
- SET/GET: 设置和获取字符串值
- MSET/MGET: 批量设置和获取字符串值
- GETRANGE/SETRANGE: 获取和设置字符串指定范围的值
- STRLEN: 获取字符串长度
- APPEND: 追加字符串

### 数值操作
- INCR/DECR: 自增/自减整数值
- INCRBY/DECRBY: 按指定增量自增/自减
- INCRBYFLOAT: 浮点数自增

### 位操作
- GETBIT/SETBIT: 获取和设置指定位的值
- BITCOUNT: 统计被设置为 1 的位数量
- BITOP: 位运算操作（AND, OR, XOR, NOT）

### 高级操作
- GETSET: 设置新值并返回旧值
- MSETNX: 批量设置多个键值对（仅当键不存在时）
- PSETEX: 设置带毫秒过期时间的键值对
- SETEX: 设置带秒过期时间的键值对
- SETNX: 仅当键不存在时设置键值对

## 使用场景
- 缓存系统
- 计数器（如网站访问量统计）
- 分布式锁实现
- Session 存储
- 限流控制

## 最佳实践
- 合理设置过期时间避免内存泄漏
- 使用适当的命令减少网络往返次数
- 注意字符串值的大小限制（512MB）
