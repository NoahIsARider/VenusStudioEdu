# Redis 集合操作

## 学习目标
- 掌握 Redis 集合类型的基本操作命令
- 理解集合类型的使用场景
- 学会使用集合运算实现复杂功能

## 主要内容

### 集合基本操作
- SADD: 向集合添加元素
- SMEMBERS: 获取集合所有元素
- SISMEMBER: 判断元素是否在集合中
- SCARD: 获取集合元素数量
- SREM: 从集合中移除元素
- SPOP: 随机弹出集合元素
- SRANDMEMBER: 随机获取集合元素（不删除）

### 集合运算
- SDIFF: 差集运算
- SINTER: 交集运算
- SUNION: 并集运算
- SDIFFSTORE: 差集运算并将结果存储到新集合
- SINTERSTORE: 交集运算并将结果存储到新集合
- SUNIONSTORE: 并集运算并将结果存储到新集合

### 集合成员操作
- SMOVE: 将元素从一个集合移动到另一个集合

## 使用场景
- 标签系统（如文章标签、用户兴趣标签）
- 共同关注（如社交网络中的共同好友）
- 黑名单/白名单管理
- 投票系统
- 去重操作

## 最佳实践
- 合理使用集合运算提高查询效率
- 注意集合元素的唯一性特征
- 根据业务需求选择合适的集合操作
