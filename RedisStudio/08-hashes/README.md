# Redis 哈希 (Hashes)

## 学习目标
- 理解哈希的数据结构和特点
- 掌握哈希的基本操作命令
- 学会使用哈希存储对象和结构化数据
- 了解哈希的性能特性和使用场景

## 主要内容

### 1. 哈希基础
- 什么是哈希
- 哈希与字符串的区别
- 字段和值的概念
- 哈希的特点和优势

### 2. 基本操作
- HSET/HGET：设置和获取字段值
- HMSET/HMGET：批量设置和获取字段值
- HGETALL：获取所有字段和值
- HEXISTS：检查字段是否存在
- HDEL：删除字段
- HLEN：获取字段数量

### 3. 数值操作
- HINCRBY：增加整数字段值
- HINCRBYFLOAT：增加浮点数字段值

### 4. 高级操作
- HKEYS：获取所有字段名
- HVALS：获取所有字段值
- HSCAN：渐进式遍历哈希
- HSTRLEN：获取字段值长度

### 5. 使用模式
- 对象存储模式
- 计数器模式
- 配置存储模式
- 会话存储模式

## 使用场景
- 存储对象数据（用户信息、商品信息等）
- 实现计数器和统计数据
- 配置信息存储
- 会话管理
- 实时数据缓存

## 最佳实践
- 使用哈希存储相关联的字段，而不是多个独立的键
- 对于小对象，使用哈希比多个字符串键更节省内存
- 注意哈希的字段数量，过大可能影响性能
- 合理使用 HSCAN 进行大数据量遍历
- 利用哈希的原子操作特性保证数据一致性
