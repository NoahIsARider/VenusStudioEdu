# RedisStudio 学习指南

这是一个系统化的 Redis 学习路径，帮助你从入门到精通掌握 Redis 数据库。

## 学习路径

### 第一阶段：基础知识 (1-3章)

1. **基础概念** (01-basics)
   - 了解 Redis 的历史和特点
   - 掌握基本的安装和配置方法
   - 学会使用 redis-cli 客户端工具
   - 理解内存数据库的工作原理

2. **数据类型** (02-data-types)
   - Redis 支持的数据类型概述
   - 内存存储机制
   - 数据持久化选项

3. **键操作** (03-keys)
   - 键的基本操作（SET、GET、DEL等）
   - 键的过期时间管理
   - 键的模式匹配和扫描

### 第二阶段：核心数据结构 (4-6章)

4. **字符串** (04-strings)
   - 字符串基本操作
   - 数值操作（INCR、DECR等）
   - 位操作（GETBIT、SETBIT等）
   - 应用场景（计数器、分布式锁等）

5. **列表** (05-lists)
   - 列表基本操作
   - 阻塞式操作（BLPOP、BRPOP等）
   - 列表的应用场景（消息队列等）

6. **集合** (06-sets)
   - 集合基本操作
   - 集合运算（交集、并集、差集）
   - 集合的应用场景（标签系统、共同关注等）

### 第三阶段：高级数据结构 (7-8章)

7. **有序集合** (07-sorted-sets)
   - 有序集合基本操作
   - 分数和排名操作
   - 范围查询
   - 应用场景（排行榜、优先级队列等）

8. **哈希** (08-hashes)
   - 哈希基本操作
   - 字段操作
   - 应用场景（对象存储、会话管理等）

### 第四阶段：高级特性 (9-11章)

9. **事务** (09-transactions)
   - Redis 事务的概念和限制
   - 事务命令（MULTI、EXEC、WATCH等）
   - 乐观锁实现
   - Lua 脚本替代方案

10. **持久化** (10-persistence)
    - RDB 快照持久化
    - AOF 日志持久化
    - 持久化配置和优化
    - 混合持久化

11. **复制** (11-replication)
    - 主从复制配置
    - 复制原理和工作机制
    - 部分重同步
    - 复制安全性

### 第五阶段：高可用与分布式 (12-13章)

12. **哨兵** (12-sentinel)
    - 哨兵系统架构
    - 哨兵配置和部署
    - 自动故障转移
    - 哨兵 API 使用

13. **集群** (13-cluster)
    - Redis 集群架构
    - 数据分片和槽位分配
    - 集群搭建和配置
    - 集群客户端路由

### 第六阶段：性能与运维 (14-16章)

14. **性能优化** (14-performance)
    - 性能监控和分析
    - 内存优化技巧
    - 网络优化
    - Pipeline 和批处理

15. **安全管理** (15-security)
    - 认证和授权
    - 网络安全配置
    - 加密传输
    - 安全审计

16. **监控** (16-monitoring)
    - Redis 内置监控命令
    - 使用 RedisInsight 监控
    - 第三方监控工具
    - 告警和通知

## 学习建议

### 实践为主
- 每个章节都要动手实践代码示例
- 完成章节后的练习题
- 尝试解决实际问题

### 循序渐进
- 按照学习路径顺序学习
- 不要跳跃章节
- 确保掌握基础知识后再学习高级内容

## 评估标准

### 初级水平
- 掌握 Redis 基本概念和数据类型
- 能够使用基本命令操作数据
- 理解键的生命周期管理

### 中级水平
- 熟练使用各种数据结构解决问题
- 理解持久化和复制机制
- 掌握事务和 Lua 脚本使用

### 高级水平
- 能够设计和部署高可用 Redis 架构
- 熟悉性能优化技巧
- 掌握集群管理和故障排查
