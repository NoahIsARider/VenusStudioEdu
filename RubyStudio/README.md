# RubyStudio - Ruby 语言学习项目

欢迎来到 RubyStudio！这是一个全面的 Ruby 语言学习项目，涵盖从基础语法到面向对象编程的核心概念。

## 📚 项目结构

```
RubyStudio/
├── 01-basics/           # 基础语法与变量
│   └── variables.rb
├── 02-control/          # 控制流（条件与循环）
│   └── control.rb
├── 03-methods/          # 方法与闭包（Block/Proc/Lambda）
│   └── methods.rb
├── 04-collections/      # 集合（数组与哈希）
│   └── collections.rb
├── 05-oop/              # 面向对象编程（类与模块）
│   └── oop.rb
├── README.md            # 项目文档
├── main.rb              # 主程序入口
└── run.sh               # 运行脚本
```

## 🚀 快速开始

```bash
# 运行所有示例
bash run.sh

# 运行特定章节
bash run.sh 01
```
