# PostgreSQL 子查询

## 学习目标
- 理解子查询的概念和用途
- 掌握标量子查询、行子查询和表子查询的使用
- 学会在 WHERE、FROM 和 SELECT 子句中使用子查询
- 了解子查询的性能优化技巧

## 主要内容

### 1. 子查询基础
- 什么是子查询
- 子查询的类型（标量、行、表）
- 子查询与连接的区别

### 2. WHERE 子句中的子查询
- 标量子查询
- 行子查询
- IN/NOT IN 子查询
- EXISTS/NOT EXISTS 子查询
- 比较操作符与子查询

### 3. FROM 子句中的子查询（派生表）
- 派生表的概念
- 派生表的别名使用
- 复杂查询的分解

### 4. SELECT 子句中的子查询
- 标量子查询在 SELECT 中的应用
- 相关子查询与非相关子查询

### 5. 子查询优化
- 子查询性能问题
- 使用连接替代子查询
- 子查询执行计划分析

## 最佳实践
- 尽可能使用连接替代复杂的子查询
- 注意子查询中的 NULL 值处理
- 使用 EXISTS 替代 IN 处理大数据集
- 避免在 WHERE 子句中使用高代价的子查询

## 实践练习
1. 编写一个查询，找出工资高于平均工资的员工信息
2. 使用子查询查找每个部门工资最高的员工
3. 编写一个查询，显示没有下属的经理信息
4. 使用派生表计算每个部门的工资统计信息
5. 优化一个包含多层嵌套子查询的复杂查询
