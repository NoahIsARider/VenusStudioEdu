# PostgreSQL 视图

## 学习目标
- 理解视图的概念和作用
- 掌握创建、修改和删除视图的方法
- 学会使用视图简化复杂查询
- 了解可更新视图和只读视图的区别

## 主要内容

### 1. 视图基础
- 什么是视图
- 视图的优点（安全性、简化查询、逻辑独立性）
- 视图与表的区别

### 2. 创建视图
- CREATE VIEW 语法
- 在视图中使用查询
- 为视图列指定别名

### 3. 管理视图
- 查看视图定义
- 修改视图（CREATE OR REPLACE VIEW）
- 删除视图（DROP VIEW）

### 4. 可更新视图
- 可更新视图的条件
- 在视图上执行 INSERT、UPDATE、DELETE
- WITH CHECK OPTION 子句

### 5. 物化视图
- 物化视图的概念
- 创建和刷新物化视图
- 物化视图与普通视图的区别

## 最佳实践
- 使用视图封装复杂查询逻辑
- 为经常使用的查询创建视图
- 注意视图的性能影响
- 合理使用物化视图提升查询性能

## 实践练习
1. 创建一个视图显示员工及其部门信息
2. 创建一个可更新视图用于管理特定部门的员工信息
3. 使用 WITH CHECK OPTION 创建安全的可更新视图
4. 创建物化视图加速复杂报表查询
5. 比较直接查询和通过视图查询的性能差异
