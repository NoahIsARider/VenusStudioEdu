# PostgreSQLStudio

这是一个全面的 PostgreSQL 学习项目，涵盖了从基础到高级的所有重要 PostgreSQL 知识。

## 项目结构

```
PostgreSQLStudio/
├── 01-basics/           # PostgreSQL 基础知识
├── 02-data-types/       # 数据类型
├── 03-tables/           # 表操作
├── 04-queries/          # 查询语句
├── 05-joins/            # 连接查询
├── 06-aggregates/       # 聚合函数
├── 07-subqueries/       # 子查询
├── 08-views/            # 视图
├── 09-indexes/          # 索引
├── 10-transactions/     # 事务处理
├── 11-triggers/         # 触发器
├── 12-stored-procedures/ # 存储过程
├── 13-functions/        # 函数
├── 14-performance/      # 性能优化
├── 15-backup-restore/   # 备份与恢复
├── 16-security/         # 安全管理
├── 17-administration/   # 管理维护
├── docker-compose.yml   # Docker 部署配置
├── QUICKSTART.md        # 快速开始指南
└── LEARNING_GUIDE.md    # 学习指南
```

## 学习目标

通过本项目，您将掌握：
- PostgreSQL 的安装与配置
- 数据库设计原则
- SQL 语言基础与高级特性
- 数据库性能优化技巧
- 数据库安全管理
- 备份与恢复策略
- 实际应用场景的最佳实践

## 部署环境

使用 Docker Compose 可以快速部署 PostgreSQL 环境，请参考 `docker-compose.yml` 文件。
