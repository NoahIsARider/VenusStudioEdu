# PostgreSQL 索引

## 学习目标
- 理解索引的工作原理和重要性
- 掌握不同类型的索引及其适用场景
- 学会创建、管理和优化索引
- 了解索引对查询性能的影响

## 主要内容

### 1. 索引基础
- 什么是索引
- 索引的工作原理
- 索引的优点和缺点
- 何时需要索引

### 2. 索引类型
- B-tree 索引（默认索引类型）
- Hash 索引
- GiST 索引
- SP-GiST 索引
- GIN 索引
- BRIN 索引

### 3. 创建和管理索引
- CREATE INDEX 语法
- 单列索引 vs 多列索引
- 唯一索引
- 部分索引
- 表达式索引

### 4. 索引优化
- 查询计划分析（EXPLAIN）
- 识别需要索引的查询
- 索引选择性
- 复合索引的列顺序

### 5. 索引维护
- 监控索引使用情况
- 重建和重组索引
- 删除无用索引
- 索引统计信息更新

## 最佳实践
- 为经常用于 WHERE、JOIN、ORDER BY 的列创建索引
- 避免过度索引，因为会降低写入性能
- 定期分析查询计划以优化索引
- 使用部分索引减少索引大小
- 对于文本搜索考虑使用 GIN 索引

## 实践练习
1. 为员工表的姓名和部门列创建合适的索引
2. 分析查询计划，识别需要索引的查询
3. 创建复合索引优化多条件查询
4. 创建部分索引优化特定条件查询
5. 比较有索引和无索引情况下的查询性能
