# PostgreSQL 聚合函数

## 学习目标
- 掌握常用聚合函数的使用方法
- 学会使用 GROUP BY 进行分组统计
- 理解 HAVING 子句的作用和使用方法

## 主要内容

### 常用聚合函数
- COUNT() - 计数函数
- SUM() - 求和函数
- AVG() - 平均值函数
- MIN() - 最小值函数
- MAX() - 最大值函数
- STRING_AGG() - 字符串聚合函数

### GROUP BY 子句
- GROUP BY 基本语法
- 按单个字段分组
- 按多个字段分组
- 分组与聚合函数结合使用

### HAVING 子句
- HAVING 与 WHERE 的区别
- HAVING 的使用场景
- HAVING 与聚合函数结合使用

### 分组查询优化
- 分组查询的执行顺序
- 索引对分组查询的影响
- 复杂分组查询的优化技巧

## 高级聚合功能
- ROLLUP 扩展
- CUBE 扩展
- GROUPING SETS 扩展

## 最佳实践
- 合理使用聚合函数提高查询效率
- 正确使用 GROUP BY 和 HAVING
- 避免在聚合查询中出现歧义
