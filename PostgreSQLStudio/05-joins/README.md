# PostgreSQL 连接查询

## 学习目标
- 掌握各种连接查询的语法和使用场景
- 理解内连接、外连接的区别
- 学会使用自连接处理层次结构数据

## 主要内容

### 内连接（INNER JOIN）
- INNER JOIN 基本语法
- 等值连接和非等值连接
- 多表连接查询

### 外连接
- LEFT JOIN（左外连接）
- RIGHT JOIN（右外连接）
- FULL OUTER JOIN（全外连接）
- 外连接与内连接的区别

### 交叉连接（CROSS JOIN）
- 笛卡尔积的概念
- CROSS JOIN 的使用场景

### 自连接
- 自连接的概念和语法
- 处理层次结构数据
- 递归查询基础

### 连接查询优化
- 连接条件的选择
- 连接顺序的影响
- 索引对连接查询性能的影响

## 最佳实践
- 根据业务需求选择合适的连接类型
- 合理使用连接条件避免笛卡尔积
- 注意连接查询的性能问题

## 实践练习
- 实现员工与部门信息的连接查询
- 查询参与项目的员工信息
- 使用自连接查询组织架构
